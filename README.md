# 林业行业标准术语共现网络（ly-standard-term-network）

本仓库为研究《基于术语共现网络的林业行业标准知识结构分析》的数据与代码存档。内容包括
2 841 项林业行业标准题录、术语共现网络的构建与分析脚本，以及论文中全部图表所依据的结果文件。

## 数据

`data/ly_standards_raw.csv`：2 841 条林业行业标准（LY/T 2 765 项、LY 76 项）题录，
字段为标准号、标准名称、所属行业、归口部门、状态（现行/废止）、发布日期、实施日期、记录号。

- 来源：全国标准信息公共服务平台（hbba.sacinfo.org.cn）行业标准数据库
- 检索条件：行业字段 = 林业
- 采集日期：2026-11-15
- 采集结果与平台返回的总记录数一致（2 841 条）

全部字段均为该平台公开题录，不含标准全文，不含任何个人身份信息、联系方式或内部资料。

## 代码

| 文件 | 作用 |
|---|---|
| `code/fetch_standards.py` | 从公开接口采集题录（复现原始数据用；接口参数为 `current`/`size`/`industry`） |
| `code/termnet_analysis.py` | 术语抽取 → 共现网络 → 社区发现 → 中心性 → 四时段演化 |
| `code/make_figures.py` | 生成论文中的 4 幅图 |

## 复现步骤

```bash
pip install -r requirements.txt
python code/termnet_analysis.py     # 输出至 results/
python code/make_figures.py         # 输出至 figures/
```

> 绘图依赖中文字体。`code/make_figures.py` 默认使用 SimHei；若系统无此字体（如 Linux / macOS），
> 请将其首部的 `plt.rcParams["font.sans-serif"]` 改为本地可用的中文字体
> （如 `Noto Sans CJK SC`、`PingFang SC`），否则图中中文将显示为方框。

若需重新采集原始数据（会覆盖 `data/ly_standards_raw.csv`）：

```bash
python code/fetch_standards.py
```

## 方法要点

1. **术语抽取**：以 GB/T 1.1—2020 对标准名称结构的规定为依据，将名称视为"领域术语＋技术属性"的组合。
   用 jieba 分词后剔除 52 个体裁词（技术规程、规范、方法、要求、等级、体系等），并合并少量同义表述。
   剔除以必要：单是"技术规程"一词就出现在 26.0% 的标准名称中，不剔除会成为网络的超级枢纽。
2. **网络构建**：术语为节点，同一标准名称内的术语共现为边，边权为共现次数。
   保留频次 ≥ 3 的术语、边权 ≥ 2 的边，得 654 节点、1 706 边。
3. **社区发现**：Louvain 算法，200 次不同随机初始化取模块度最优者，并报告 Q 的取值区间。
   因 Python 字符串哈希随机化，节点须按排序顺序插入方可复现。
4. **模块耦合**：模块间共现权重占全部边权的比例，用于衡量体系的整合程度。
5. **时段划分**：2009 年及以前（797 项）、2010—2014 年（643 项）、2015—2019 年（869 项）、
   2020—2026 年（520 项）。

## 主要结果

| 指标 | 数值 |
|---|---|
| 网络规模 | 654 节点 / 1 706 边 |
| 密度 / 平均聚类系数 | 0.008 / 0.496 |
| 最大连通分量占比 | 91.0% |
| 模块度 Q | 0.734 6（200 次区间 0.726 4—0.734 6） |
| 主要模块数（规模 ≥ 5） | 16，覆盖 91.0% 节点 |
| **模块间共现权重占比** | **15.0%** |
| 中介中心性最高术语 | 木材 0.237 5、森林 0.196 1、林业 0.127 0 |
